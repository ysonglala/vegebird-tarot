# Tarot Draw Site (Mystic Cat)

一个偏「占星猫」氛围的塔罗抽牌网页 MVP：
- 支持 **单张抽牌 / 三张牌阵（过去-现在-未来）**
- 抽到的牌会随机出现 **正位/逆位**（可在设置里调整概率）
- 有 **洗牌/翻牌动效**、星尘背景、猫系神秘风 UI
- 自带 **大阿尔卡那 22 张**的基础含义（示例数据，后续可扩展 78 张）

> 说明：本项目不含任何占星猫或塔罗牌原图资源（避免版权问题），卡面是抽象设计 + 文案展示。

## 本地运行

任选其一启动静态服务器（推荐）：

### 方式 A：Python
```bash
cd tarot-mystic-cat
python -m http.server 5173
```
然后访问： http://localhost:5173

### 方式 B：Node
```bash
cd tarot-mystic-cat
npx http-server -p 5173
```

## 目录结构
- `index.html` 入口
- `styles.css` 样式
- `app.js` 逻辑 + 卡牌数据
