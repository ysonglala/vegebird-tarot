# 菜鸟塔罗抽牌系统 · Vegebird Tarot

Vegebird Tarot 是一个原创的塔罗抽牌网页项目，面向移动端体验设计，采用完整的仪式化流程：

**提问 → 选择牌阵 → 洗牌 → 数字抽牌 → 翻牌解读**

项目当前基于 **传统伟特塔罗 78 张牌** 进行设计与扩展，强调沉浸感、交互感与可持续迭代的产品结构。

## 项目特性

- 原创产品结构与前端交互设计
- 移动端 H5 风格界面
- 支持多种牌阵：
  - 无牌阵三张
  - 过去 / 现在 / 未来
  - 时间流
  - 起因 / 过程 / 结果
  - 二选一牌阵
  - 自定义牌阵
- 支持自定义牌阵名称、牌数与牌位含义
- 支持洗牌、数字抽牌、逐张翻牌
- 结果页支持单牌详情查看
- 已为后续原创插画牌图预留展示位

## 项目定位

本项目为原创塔罗互动产品雏形，重点在于：

- 更完整的用户参与感
- 更自然的抽牌仪式流程
- 更适合前台展示的移动端体验
- 后续可持续扩展为正式产品

## 技术结构

本项目当前为纯静态前端站点：

- `index.html`：页面结构
- `styles.css`：界面样式
- `app.js`：抽牌逻辑、牌阵逻辑、结果交互

无需后端即可运行与部署。

## 本地运行

### 方式 A：Python
```bash
cd vegebird-tarot-pages
python -m http.server 5173
```
访问：
`http://localhost:5173`

### 方式 B：Node
```bash
cd vegebird-tarot-pages
npx http-server -p 5173
```
