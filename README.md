# 菜鸟塔罗抽牌系统 · Vegebird Tarot

> 一个原创的移动端塔罗抽牌产品雏形。  
> 以仪式感、参与感与前台体验为核心，围绕传统伟特塔罗 78 张牌持续构建。

---

## ✨ 项目简介

**Vegebird Tarot（菜鸟塔罗抽牌系统）** 是一个原创塔罗互动网页项目。  
它不是简单的“点一下出结果”，而是把抽牌过程设计成一条完整的体验流程：

**提问 → 选择牌阵 → 洗牌 → 数字抽牌 → 翻牌解读**

项目当前聚焦于：
- 更自然的抽牌节奏
- 更强的用户参与感
- 更适合移动端展示的界面结构
- 更容易扩展为正式产品的前端架构

## 🃏 当前功能

### 抽牌流程
- 输入问题
- 选择牌阵
- 仪式化洗牌
- 用户数字抽牌
- 逐张翻牌查看结果

### 已支持牌阵
- 无牌阵三张
- 过去 / 现在 / 未来
- 时间流
- 起因 / 过程 / 结果
- 二选一牌阵
- 自定义牌阵

### 已实现交互
- 移动端 H5 风格单页流程
- 多步骤进度导航
- 动态牌位输入
- 结果页翻牌效果
- 单牌详情弹层
- 后续图片资源预留位

## 📱 产品特点

- **原创前端体验设计**：强调仪式感而不是工具感
- **移动端优先**：更贴近真实用户使用场景
- **可扩展牌阵系统**：支持固定模板与自定义牌阵
- **纯静态前端部署**：无需后端即可访问与演示
- **适合持续迭代**：内容层、图片层、分享层都可继续升级

---

## 🧩 技术结构

当前项目为纯静态站点：

- `index.html`：页面结构
- `styles.css`：界面样式
- `app.js`：抽牌逻辑、牌阵逻辑、结果交互

这意味着它可以非常方便地部署到：
- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages

## 🚀 本地运行

### Python
```bash
cd vegebird-tarot-pages
python -m http.server 5173
```
访问：
`http://localhost:5173`

### Node
```bash
cd vegebird-tarot-pages
npx http-server -p 5173
```
